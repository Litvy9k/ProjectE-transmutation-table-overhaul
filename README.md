# Transmutation Terminal

> [!IMPORTANT]
> **This mod was made by Claude Opus 5.5** (Anthropic's AI model). The code, textures and docs were all written by Claude.

An AE2-style terminal for the ProjectE Transmutation Table and Tablet: a scrollable, searchable, sortable grid of every item you have learned.

- Minecraft 1.21.1, NeoForge
- Requires [ProjectE](https://www.curseforge.com/minecraft/mc-mods/projecte) 1.1.0+, optional JEI / EMI
- Install on both client and server

Full feature list: [docs/CURSEFORGE.md](docs/CURSEFORGE.md)

## Build

```
./gradlew build
```
