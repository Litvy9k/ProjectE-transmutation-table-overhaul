# TransTable Overhaul

> [!IMPORTANT]
> **This mod was made by Claude Opus 5.5** (Anthropic's AI model). The code, textures and docs were all written by Claude.

An AE2-style terminal for the ProjectE Transmutation Table and Tablet: a scrollable, searchable, sortable grid of every item you have learned. Also adds a Transmutation Crafting Table with a 3x3 grid and JEI recipe transfer.

- **This branch: Minecraft 1.20.1, Forge 47** (also runs on NeoForge 1.20.1). The 1.21.1 NeoForge version is on `main`.
- Requires [ProjectE](https://www.curseforge.com/minecraft/mc-mods/projecte) 1.0.1+ for 1.20.1, optional JEI / EMI
- Install on both client and server

Full feature list: [docs/CURSEFORGE.md](docs/CURSEFORGE.md)

## Build

```
./gradlew build
```
